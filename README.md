# Волосач — сайт барбершопа

Лендинг для барбершопа **«Волосач»** (Мончегорск, Мурманская область), ул. Гагарина, 11.

## Файлы

| Файл | Описание |
|------|----------|
| [`index.html`](index.html) | Весь сайт — самодостаточный HTML, CSS и JS внутри, без сборки |

Особенности: кастомный курсор в виде ножниц, кликабельная запись через Dikidi,
раздел «Атмосфера» с фото клиентов (увеличение по клику до формата А6, листание
стрелками), вращающиеся барбер-столбы по краям страницы, карта, услуги и цены,
ссылки на VK/Telegram/WhatsApp/звонок.

## Деплой

Сайт статический — не требует сборки. Подключите репозиторий к Vercel
(Framework Preset: **Other** / No build step) — `index.html` лежит прямо
в корне репозитория, поэтому Root Directory менять не нужно, сайт
развернётся как есть.
